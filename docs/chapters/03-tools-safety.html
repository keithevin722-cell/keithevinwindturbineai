Chapter 3: Tools & Safety

Core tools

  • Drill press or quality hand drill with step bits
  • Angle grinder, metal saw, deburring tools
  • Torque wrench and full socket/spanner set
  • Crimp tools for terminals, heat gun for heat-shrink
  • Multimeter + clamp meter; optional handheld anemometer and tachometer

PPE and job safety gear

  • Safety glasses + face shield
  • Cut-resistant gloves, hearing protection
  • Harness/fall protection for tower work
  • Class C fire extinguisher and first-aid kit
Critical safety rules:
  • Never work on wiring while energized. Lock-out/tag-out if possible.
  • Never approach spinning blades in loose clothing.
  • Use proper lifting technique and helpers for tower/rotor assembly.
  • Battery banks can deliver dangerous fault current; fuse close to battery positive.
